操作说明

  • JS 错误 → JAVASCRIPT_ERROR；坏链图片 → RESOURCE_ERROR
  • Promise reject → PROMISE_ERROR（Error / 非 Error 原因都规范化）
  • HTTP：2xx 只进面包屑；5xx / status 0 → 上报 FETCH_ERROR
  • console / 点击 / 路由 → 只进面包屑，不单独上报
  • SDK 自身上报的 /report 被 isSdkTransportUrl 拦截，不会自循环
  • 同错误连点：第 3 次起被 maxDuplicateCount 去重丢弃
